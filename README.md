# Persian Quiz

MERN monorepo. API and UI live in this repository.

- `backend/` — Express + MongoDB API
- `frontend/` — Vite + React UI

## Backend

```bash
cd backend
bun install
bun run dev
```

## Frontend

```bash
cd frontend
bun install
bun run dev
```

Frontend expects the API at `VITE_WEBSITE_URL` (see `frontend/.env`).
